Run Clubs in Mainz

In Mainz gibt es aktuell 13 Run Clubs und Laufgruppen im Verzeichnis, darunter AG Run Club, Altbau Run Club, Hafen Runners und Hue & You Run Club.

Ein Run Club ist eine Laufgruppe, die sich regelmäßig zu festen Zeiten trifft, meist ohne Mitgliedschaft und oft mit gemeinsamem Ausklang im Café. Du musst weder schnell noch fit sein, die meisten Gruppen heißen Einsteiger ausdrücklich willkommen.

Zum Rhythmus: AG Run Club (Montags 19 Uhr). Altbau Run Club (Mittwochs 17:30 Uhr). LaufLeben Running Crew e.V. (Dienstags 19 Uhr).

So gelingt der erste Lauf

Komm ein paar Minuten früher, sag, dass du neu bist, und frag nach Strecke und Tempo. Bequeme Sportkleidung und eingelaufene Schuhe reichen. Alles Wichtige für Einsteiger steht im Ratgeber Was ist ein Run Club?

Häufige Fragen

Welche Run Clubs gibt es in Mainz?

Im Verzeichnis stehen aktuell 13 Einträge, unter anderem AG Run Club, Altbau Run Club, Hafen Runners, Hue & You Run Club und Kaura Running Club. Alle findest du in der Liste auf dieser Seite, die Links prüfen wir alle zwei Wochen.

Muss ich schnell sein, um bei einem Run Club mitzulaufen?

Nein. Viele Run Clubs laufen in mehreren Gruppen mit unterschiedlichem Tempo, und niemand wird zurückgelassen. Schreib vorab kurz, welches Tempo du läufst, dann weißt du, welche Gruppe passt.

Was kostet ein Run Club?

Viele Run Clubs sind kostenlos, einige finanzieren sich über Sponsoren oder bitten um freiwillige Beiträge. Die parkrun-Läufe am Samstagmorgen sind ebenfalls kostenlos, du registrierst dich dafür einmal vorab.

Wie finde ich in Mainz den passenden Run Club?

Vergleiche zwei bis drei Gruppen nach Tempo, Treffzeit und Treffpunkt und probiere sie aus. Meist erkennst du schon nach dem ersten Besuch, ob die Stimmung passt.
